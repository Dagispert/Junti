# Junti

Aplicación móvil de conexión y memoria compartida: grupos privados donde amigos, familia o pareja que viven lejos comparten pequeños momentos del día a día, que con el tiempo se convierten en el archivo de su historia común.

**Estado:** prototipo navegable con datos de ejemplo y esquema de base de datos. Sin cuentas ni servidor todavía.

## Contenido

- [`docs/`](docs/01-analisis-y-definicion-de-producto.md): análisis y definición de producto (viabilidad, experiencia de usuario, arquitectura, modelo de datos, alcance del MVP, plan y decisiones).
- [`mobile/`](mobile/README.md): la app (Expo / React Native). Incluye cómo probarla en tu móvil.
- [`supabase/`](supabase/README.md): esquema de la base de datos con sus reglas de privacidad y pruebas.
